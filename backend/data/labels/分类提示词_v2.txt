F类【仅】适用于以下四种情形：
  (1) 股东身份、控股股东/实控人本身的问题；
  (2) 控制权归属与变更、股权质押冻结、股东增减持等权益变动；
  (3) 董监高的任免、履职、人员变动本身；
  (4) 内部控制制度、三会运作、公司独立性本身。

【以下情况一律不归F】——即使文中出现"股""权""人员""决策程序"等字眼：
  ✗ 关注点核心是财务科目（往来款、净资产、应收款）→ 归 C 或 A
  ✗ 关注点核心是买卖资产/股权的交易安排、定价、优先受让权 → 归 E
  ✗ 关注点核心是员工人数、薪酬、人力成本 → 归 A（经营）
  ✗ 关注点核心是经营是否能持续、生产是否中断 → 归 A06
  ✗ 关注点核心是披露是否及时/完整 → 归 G
  ✗ 关注点核心是股价异动、市场传闻 → 归 H

判定口诀：先问"监管真正盯的是哪个科目或事项"，只有当答案本身就是"股东/控制权/董监高/内控"时，才用F。

三、易混主题判定规则
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

2. A ↔ C：核心是经营成果（营收、利润、净资产规模）→ A；核心是某项资产的账面价值与可回收性 → C
3. B ↔ C：核心是"会计上怎么确认计量"→ B；核心是"这项资产本身质量如何"→ C
4. B ↔ E：核心是会计处理方法 → B；核心是交易安排本身 → E
5. C01 ↔ C06：应收账款及坏账 → C01；往来款、其他应收款、预付款、投资类资产 → C06
6. E01 ↔ E06：涉及评估报告、评估方法、评估参数 → E06；仅讨论价格是否公允 → E01
7. G04 ↔ G07：涉及具体监管行动（立案、处罚、监管措施）→ G07；仅披露不完整 → G04
8. 资产减值：按【具体资产对象】选二级（应收→C01、存货→C02、商誉→C03、固定资产/在建工程→C04、无形资产→C05、其他→C06）；"是否充分"用质疑性质Q08表达，不影响主题归属

★ Q05"合理性"被严重滥用，请严格按以下规则收窄：

【只有出现这些语义才用Q05】原因是否合理、安排是否合理、变动是否合理、定价是否合理、
  必要性如何、为何如此处理——即监管在质疑"这么做说不说得通"。

【以下情况不要用Q05】：
  → 仅要求补充/列示/说明某项事实信息（"说明进展""列示明细""披露具体内容"）：用 Q03完整性
  → 涉及未来经营延续、计划可执行性、持续经营影响（"可持续性""可行性""能否恢复"）：用 Q10可持续性
  → 质疑够不够、是否充分（减值计提是否充分、审计证据是否充分、风险揭示是否充分）：用 Q08充分性
  → 质疑是否过于乐观、估计是否激进、假设是否谨慎：用 Q09审慎性
  → 质疑是否属实、是否存在、请核实：用 Q01真实性
  → 涉及时间、是否及时（"为何未及时""是否及时披露"）：用 Q12及时性
  → 涉及前后矛盾、数据打架、勾稽不符：用 Q04一致性
  → 涉及是否违反规定、程序是否合规：用 Q11合规性
  → 涉及价格是否公平、对价是否公允：用 Q06公允性
  → 涉及交易是否有真实商业目的：用 Q07商业实质
  → 涉及独立性（关联方独立性、中介机构独立性）：用 Q13独立性

★ Q08 vs Q09 边界：
  Q08充分性回答"够不够"（减值计提是否充分、证据是否充分适当、披露依据是否充分）
  Q09审慎性回答"是否过于乐观"（会计估计是否激进、现金流假设是否乐观、是否低估损失）
  两者同时出现时：主标Q08、辅标Q09

★ 兜底：纯粹要求"说明/列示某项事实"、无明确质疑属性的，用Q03，并将confidence设为0.6以下。
