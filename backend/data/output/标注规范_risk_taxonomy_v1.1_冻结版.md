## 第五届中国研究生金融科技创新大赛 · 东吴证券第6题 · 任务1核心标准

> **状态：冻结版 v1.1（已通过300条双人独立试标验证）**
> 本规范基于官方金标准（474家公司、1483个问询事件、10481条监管关注点）的真实分布，
> 经"16类初稿 → 78子类完整版 → 45核心+扩展简化版 → 300条试标验证"四轮迭代形成。
> 本规范是任务1的唯一权威依据：标注、抽取Prompt编写、分类评分均以此为准。

## 一、总体结构（多维度标注框架）

采用"主分类 + 属性 + 元数据"的多维度正交结构，避免单一分类导致的维度混杂：

```
主分类维度：风险主题（一级 + 二级）
属性维度一：质疑性质
属性维度二：风险发生或核查环节
元数据维度：文档载体、证据载体、涉及主体
```

**每条独立监管关注事项的标注字段：**

| 字段 | 要求 | 说明 |
|---|---|---|
| primary_theme_l1 | 必选1个 | 一级风险主题（8选1） |
| primary_theme_l2 | 必选1个 | 核心二级主题（45选1） |
| secondary_theme_l2 | 可选，最多1个 | 辅助二级主题 |
| primary_question_type | 必选1个 | 主要质疑性质（13选1） |
| secondary_question_type | 可选，最多1个 | 辅助质疑性质 |
| primary_stage | 必选1个 | 主要风险环节（8选1） |
| secondary_stage | 可选，最多1个 | 次要风险环节 |
| document_carrier | 自动提取 | 文档载体（元数据） |
| evidence_carriers | 多标签 | 证据载体（元数据） |
| involved_entities | 多标签 | 涉及主体（元数据） |

## 二、主分类维度：风险主题（8个一级 + 45个核心二级）

回答：**监管主要在关注什么业务问题或风险对象？**

### A 经营业绩与商业模式（6个核心）
- A01 收入规模与收入变动
- A02 成本费用与毛利率
- A03 利润、扣非利润与业绩波动
- A04 业务模式与商业实质
- A05 客户与供应商集中度
- A06 经营稳定性与持续经营能力
- *扩展：重大合同与订单、产能产量与项目进展、主营业务具体变化*

### B 财务报告与会计处理（5个核心）
- B01 收入确认与截止性
- B02 成本费用确认与资本化
- B03 会计政策、会计估计与差错更正
- B04 合并报表范围
- B05 非经常性损益与政府补助
- *扩展：科目列报与重分类、其他会计确认和计量*

### C 资产质量与减值（6个核心）
- C01 应收账款与坏账准备
- C02 存货与跌价准备
- C03 商誉与商誉减值
- C04 固定资产与在建工程
- C05 无形资产、研发支出与资本化
- C06 其他资产与投资资产
- *扩展：资产减值计提充分性、资产真实性、资产可回收性*

### D 资金、现金流与偿债（6个核心）
- D01 经营现金流与利润匹配
- D02 货币资金真实性、受限资金与存贷双高
- D03 债务结构与偿债能力
- D04 债务逾期、违约与展期
- D05 担保、抵质押与或有负债
- D06 融资安排与募集资金使用
- *扩展：存贷双高（作为D02下的风险模式）、特定融资工具、单项诉讼或仲裁*

### E 交易、关联方与资本运作（7个核心）
- E01 交易商业实质、合理性与定价公允性
- E02 关联方识别与关联交易
- E03 非经营性资金占用
- E04 资产购买、出售与年末突击交易
- E05 并购重组与重大资产交易
- E06 估值方法与评估合理性
- E07 业绩承诺、补偿安排与对赌协议
- *扩展：对外投资与普通股权投资*

### F 股东、控制权与公司治理（6个核心）
- F01 控股股东与实际控制人
- F02 控制权变更与稳定性
- F03 股权质押、冻结与司法处置
- F04 增减持、回购、股权激励与权益变动
- F05 董监高履职与人员变动
- F06 内部控制、三会治理与公司独立性
- *扩展：子公司管控、同业竞争、业务独立性*

### G 审计、披露与监管合规（7个核心）
- G01 审计意见与非标准审计意见
- G02 审计证据充分性与审计范围受限
- G03 会计师事务所变更与中介机构胜任能力
- G04 信息披露完整性
- G05 信息披露及时性
- G06 前后披露一致性、数据准确性与勾稽关系
- G07 立案调查、监管处罚与其他合规事项
- *扩展：风险提示不足、律师核查不足、评估机构核查不足、其他中介责任*

### H 市场交易与证券行为（2个核心）
- H01 股价、成交量与市场交易异常
- H02 市场传闻、媒体报道与澄清
- *扩展：停复牌事项、内幕信息与敏感期交易、其他证券市场行为*
- *说明：H类因财务数据缺股价成交字段，为尾部类别，主要服务任务1文本识别与任务4报告；暂无法归类样本进入H-OTHER观察池*

**核心二级主题合计：6+5+6+6+7+6+7+2 = 45个**

## 三、属性维度一：质疑性质（13个）

回答：**监管具体在质疑该事项的什么属性？** 每条标注1个主要 + 最多1个辅助。

- Q01 真实性
- Q02 准确性
- Q03 完整性
- Q04 一致性
- Q05 合理性
- Q06 公允性
- Q07 商业实质
- Q08 充分性
- Q09 审慎性
- Q10 可持续性
- Q11 合规性
- Q12 及时性
- Q13 独立性

*已合并/降级（不作全局核心性质）：必要性→合理性；可验证性→真实性/充分性；计量可靠性→准确性/充分性；依据适当性→合理性/充分性；程序规范性→合规性；可回收性→资产主题的专业扩展属性*

## 四、属性维度二：风险发生或核查环节（8个）

回答：**风险在哪个流程节点暴露或被核查？** 每条标注1个主要 + 最多1个次要。
（本维度既含业务风险形成环节，也含审计、披露、监管核查环节，故称"发生或核查环节"）

| 编码 | 环节 | 主要覆盖内容 |
|---|---|---|
| P01 | 业务形成与交易设计 | 商业模式、交易结构、关联交易安排、并购重组、对赌协议等 |
| P02 | 合同履约与资金流转 | 合同执行、货物交付、回款付款、资金占用、担保履行 |
| P03 | 会计确认与计量 | 收入确认、成本确认、减值、估值、资本化、会计政策估计 |
| P04 | 财务列报与报表勾稽 | 科目列报、合并报表、重分类、报表间勾稽、数据一致性 |
| P05 | 内部控制与治理审批 | 董事会/股东大会审批、关联方回避、内控执行、董监高履职 |
| P06 | 审计鉴证与中介核查 | 审计证据、审计意见、评估报告、法律意见、中介核查 |
| P07 | 信息披露与风险提示 | 年报/公告披露、完整性、及时性、前后一致性、风险揭示 |
| P08 | 监管调查、整改与反馈 | 问询回复、立案调查、处罚、整改、持续督导 |

## 五、元数据维度（多标签，主要用于案例检索与溯源）

### 文档载体（document_carrier）
年报、半年报、季报、业绩预告/快报、权益分派公告、并购重组公告、关联交易公告、担保公告、问询函、回复函、审计报告、内部控制报告、立案或处罚公告、其他监管文件

### 证据载体（evidence_carriers）
利润表、资产负债表、现金流量表、财务报表附注、交易合同、资金流水、评估报告、审计意见、董事会决议、监事会决议、股东大会决议、法律意见书、市场交易数据、业务台账或明细表、其他原始凭证

### 涉及主体（involved_entities）
上市公司、控股股东、实际控制人、第一大股东、董事、监事、高级管理人员、子公司、联营或合营企业、关联方、客户、供应商、交易对手、债权人、担保对象、审计机构、评估机构、律师事务所、保荐机构或财务顾问、其他中介机构、监管机构、其他主体

## 六、标注约束汇总

1. 每条事项 **必选** 1个一级主题、1个核心二级主题、1个主要质疑性质、1个主要风险环节。
2. **可选** 最多1个辅助二级主题、最多1个辅助质疑性质、最多1个次要风险环节。
3. 不允许无上限多选，以避免标签泛化、保证标注一致性。
4. 主标注优先标"风险对象"（主题），"充分性/审慎性/可回收性"等作为质疑性质标注，不作主主题。
5. 无法归入核心二级的样本，进入对应大类的 OTHER 观察池，不强行归类。

## 七、试标验证结果（冻结依据）

2026年8月，从10481条监管关注点中分层抽取300条，由两名金融专业标注员**独立标注**（互不商量），验证结果如下：

### 7.1 冻结条件达标情况

| 冻结条件 | 目标 | 实际结果 | 判定 |
|---|---|---|---|
| 一级主题未覆盖率 | < 5% | 0%（A–H八类全部使用） | ✅ 达标 |
| 二级主题无法归类率 | < 10% | 5.7%（17/300） | ✅ 达标 |
| 各核心类别有真实样本 | — | 48个二级主题被实际使用 | ✅ 达标 |
| 标注员一致率 | — | 见下表 | ✅ 良好 |

### 7.2 双人独立标注一致率

| 维度 | 一致率 | 评价 |
|---|---|---|
| 一级风险主题 | **90.7%**（272/300） | 优秀，类别边界清晰 |
| 核心二级主题 | **80.0%**（240/300） | 良好，45类中选1仍达八成一致 |
| 主要质疑性质 | 74.7%（224/300） | 可接受，主观判断成分较高 |
| 主要风险环节 | 70.0%（210/300） | 可接受，已降为参考性标注 |

一致率呈现"维度越粗越高"的合理梯度，符合标注任务规律。

### 7.3 一级主题实际分布（300条样本）

| 一级主题 | 条数 | 占比 |
|---|---|---|
| E 交易、关联方与资本运作 | 68 | 22.7% |
| C 资产质量与减值 | 57 | 19.0% |
| A 经营业绩与商业模式 | 45 | 15.0% |
| D 资金、现金流与偿债 | 39 | 13.0% |
| F 股东、控制权与公司治理 | 33 | 11.0% |
| G 审计、披露与监管合规 | 29 | 9.7% |
| B 财务报告与会计处理 | 24 | 8.0% |
| H 市场交易与证券行为 | 5 | 1.7% |

H类占比1.7%，确认为尾部类别，维持"保留但不作标注重点"的处理。

**结论：四项冻结条件全部达标，标注体系 v1.1 正式冻结。**

## 九、易混类别判定指引（依据试标分歧分析制定）

试标中共出现一级主题分歧28条、二级60条、质疑性质76条、环节90条。分析混淆模式后，制定以下判定规则。**本节同时作为AI标注提示词的核心内容。**

### 9.1 一级主题易混对

| 易混对 | 分歧次数 | 判定规则 |
|---|---|---|
| A 经营业绩 ↔ E 交易关联方 | 4 | 关注点核心是**交易本身的结构与定价** → E；核心是**交易对经营业绩的影响** → A |
| E 交易关联方 ↔ F 股东治理 | 3 | 核心是**交易安排本身** → E；核心是**股东/控制权/治理程序** → F |
| A 经营业绩 ↔ B 财务报告 | 2 | 核心是**业务经营实质** → A；核心是**会计确认与列报方法** → B |

### 9.2 二级主题易混对（重点）

| 易混对 | 分歧次数 | 判定规则 |
|---|---|---|
| **E01 ↔ E06** | 5 | 涉及**评估报告、评估方法、评估参数** → E06；仅讨论**交易价格是否公允、不涉及评估技术** → E01 |
| **B03 ↔ B05** | 5 | 核心是**补助/损益的性质认定** → B05；核心是**会计处理方法是否恰当** → B03 |
| **G04 ↔ G07** | 3 | 涉及**具体监管行动（立案、处罚、监管措施）** → G07；仅为**披露内容不完整** → G04 |
| A04 ↔ E05 | 2 | 核心是**业务模式本身** → A04；核心是**并购重组交易** → E05 |
| C01 ↔ C06 | 2 | **应收账款及其坏账准备** → C01；**预付款、其他应收款、投资类资产** → C06 |

### 9.3 质疑性质易混对（重点）

| 易混对 | 分歧次数 | 判定规则 |
|---|---|---|
| **Q08充分性 ↔ Q09审慎性** | 10 | **涉及减值、准备计提一律用 Q08充分性**；Q09仅在明确讨论会计估计偏乐观/偏悲观时使用 |
| **Q03完整性 ↔ Q05合理性** | 10 | 监管要求"**补充披露/补充说明某项内容**" → Q03；要求"**说明原因/说明合理性**" → Q05 |
| **Q05合理性 ↔ Q10可持续性** | 7 | 明确涉及**持续经营能力、业务可持续性** → Q10；其他一般合理性质疑 → Q05 |
| Q01真实性 ↔ Q03完整性 | 6 | 质疑**内容是否属实、是否存在** → Q01；质疑**是否披露齐全** → Q03 |
| Q04一致性 ↔ Q05合理性 | 6 | 涉及**前后数据/表述矛盾** → Q04；涉及**原因是否说得通** → Q05 |

**总原则：优先按监管的措辞判定，而非按标注员的理解推测。**

### 9.4 风险环节易混对

| 易混对 | 分歧次数 | 判定规则 |
|---|---|---|
| **P01 ↔ P03** | 14 | 质疑**交易如何设计、商业安排** → P01；质疑**账务如何确认计量** → P03 |
| P01 ↔ P07 | 11 | 质疑**业务安排本身** → P01；质疑**是否披露、披露是否充分** → P07 |
| P03 ↔ P04 | 10 | **确认与计量方法** → P03；**列报、科目分类、报表勾稽** → P04 |
| P01 ↔ P05 | 9 | **交易设计** → P01；**审批程序、内控执行** → P05 |

**说明：风险环节维度一致率为70%，主观判断成分较高，已降为参考性标注，用于辅助分析与报告组织，不参与分类准确率考核。**

### 9.5 标注填写规范

1. **二级主题必须填写完整编码**（如 A06、C01），不得只填一级字母（如"A"、"C"）。
2. 每条必填：一级主题、核心二级主题、主要质疑性质、主要环节。
3. 无法归入核心二级的样本，标记"无法归类"并进入对应大类 OTHER 观察池，不强行归类。
