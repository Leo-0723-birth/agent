# 上市公司监管问询概率预测建模（预测建模agent）

三窗口（30/60/90 天）× 三模型（RandomForest / LightGBM / XGBoost）的监管问询概率预测流水线。
基于队员建模结果重构，含 F1 特征 Top-50 筛选、数据处理、训练与 SHAP 归因输出。

## 目录

```
预测建模agent/
├── README.md                         ← 本文件
├── 01_原数据/                        原数据快照（F1-F6 + 事件）
```

## 快速使用

```bash
# 1. 依赖
pip install pandas numpy scipy lightgbm xgboost scikit-learn imbalanced-learn shap pyarrow joblib

# 2. 数据处理（输出 05_模型输出/processed_dataset.csv）
python 02_数据处理/build_dataset.py

# 3. 训练（输出 05_模型输出/{30d,60d,90d}/）
python 04_建模脚本/train_models.py
```

## 输出说明

- **predictions_{w}d.csv**：测试集每家公司的三模型概率 + 集成概率 + 真实标签
- **shap_{w}d.csv**：每条测试样本的 Top-5 特征 SHAP 贡献（positive_risk/negative_risk 方向）
- **risk_rank_{w}d.csv**：按集成概率降序的公司风险排序 + A-F 风险等级
- **model_summary.json**：各窗口 × 各模型 AUC/AP/F1/Precision/Recall/Top10%Recall
