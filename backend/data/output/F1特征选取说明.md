# F1 特征选取说明

## 为什么从 300 维筛到 50 维

F1 是"监管问询函语义 + 公告文本语义"经 BGE 向量化 + 时间衰减池化 + PCA 得到的 **300 维主成分**（`regulatory_inquiry_semantic_000~299`）。

**问题**：300 维中大量主成分与"是否被问询"几乎无关——Spearman |corr| 普遍 < 0.01（本次筛选后 Top-50 的 |corr| 区间约 0.078 ~ 0.021）。把 250 个低效维度一起喂给树模型会：
- **稀释分裂收益**：每次分裂要遍历更多无信息特征，模型偏向噪声；
- **增加过拟合**：维度/样本比变差；
- **降低可解释性**：SHAP 归因被低效特征占据。

**做法**：在**训练集**上计算每维与 `target_60d` 的 **Spearman 秩相关系数**，取绝对值 Top-50（复用你上一次的选取结果，见 `semantic_feature_descriptions_原版.md` 的 50 维清单与业务含义）。

## 时间口径
- 只在 **Train** 集计算相关（防泄漏）；
- 相关目标用 `target_60d`（主窗口）；
- 有效样本 = `target_60d >= 0`（有观察窗口的样本）。

## 与"低效特征干扰"的关系
降维后：特征 300+68+35+19+15+12 ≈ 449 → 数据经零方差/高相关/重要性筛选后实际进入模型的约 **150-250 维**，其中 F1 仅保留 50 维，显著降低干扰。
