# 技能 02 · 数据资产与特征工程

## 特征家族（任务2 口径）
| 族 | 内容 | 维度 | 来源 |
|---|---|---|---|
| F1 | 公告语义特征（风险事件计数/主题分布/窗口聚合） | Top-50（Spearman 选取） | 公告研读 Agent |
| F2 | 财务特征（Beneish M 分数/Piotroski/Benford/行业偏离） | 67 | f2_calc.py |
| F3 | 市场特征（腾讯 K 线：波动/量价/回撤等） | 35 | market_fetch.py |
| F4/F5/F6 | 舆情/治理/问询历史特征（离线预处理表） | — | feature_loader.py |
| 标签 | 30/60/90 天是否收到问询函 | 3 | 官方 GT |

## 关键数据资产
- **建模数据框架**：`backend/data/modeling/README.md`（训练/预测分离：raw 源头 → preprocessed 离线表 → processed_dataset 训练集 → fill 兜底字典 → output 评估产物；预测用实时爬取数据 + fill 中位数兜底）
- **案例库**：`backend/data/vector_db/case_db.json`（4785 份问询函）+ `case_vectors.npy`（BGE 1024 维）+ `case_meta.json` + chunk 段落库
  - 重建：`python -m backend.scripts.build_case_db --force --backend bge`
- **建模数据集**：`backend/data/modeling/processed_dataset.csv`（37222 行 × 204 列）
  - 重建：`python -m backend.scripts.build_modeling_dataset`
- **预测模型**：`backend/models/predictor/`（RF/LGB/XGB × 30/60/90d + models_manifest.json + feature_importance）
  - 训练：`python -m backend.scripts.train_models`
- **预测兜底字典**：`backend/data/modeling/fill/fill_median_{30,60,90}d.csv`（训练集 Train 中位数，实时特征缺失列用）

## 向量与 Embedding（backend/skills/embedding.py）
- 默认 BGE-large-zh-v1.5（1024 维），权重在 `backend/models/embedding/hub/`（HF_HOME 指向项目内）
- 加载失败自动回落 fallback（65536 维哈希）→ **维度守卫**会拦截语义通道（案例检索只剩标签通道），这是设计行为，不是 bug
- 案例库是 1024 维，query 必须是 BGE；若出现"向量维度不匹配"，检查 BGE 是否加载成功

## 缓存与索引
- 公告索引：`backend/data/index/000004_SZ_index.json`（每公司一个，首次自动建）
- PDF 缓存：`backend/data/cache/pdfs/`（下载+提取结果，重跑秒级）
- OCR：rapidocr 3.9.2 + onnxruntime（扫描型 PDF 逐页识别，带置信度审计元数据）
