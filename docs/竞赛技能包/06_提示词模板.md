# 技能 06 · LLM 提示词模板与结构化输出

## 调用入口（backend/llm.py）
```python
from backend.llm import chat, chat_json, chat_structured

text = chat("system", "prompt", temperature=0.1)              # 普通文本
data = chat_json("system", "prompt", schema_hint="risk")      # JSON 对象（失败返回 {}）
factor = chat_structured(RiskFactorModel, "system", "prompt") # Pydantic 强校验（失败 None）
```

## 结构化输出（chat_structured）用法
```python
from pydantic import BaseModel, Field

class RiskFactor(BaseModel):
    category: str = Field(description="风险类别（官方二级主题）")
    severity: int = Field(ge=1, le=5, description="严重度 1-5")
    evidence: str = Field(description="原文证据（必须逐字来自公告）")

factor = chat_structured(
    RiskFactor,
    "你是监管问询领域的金融风险抽取器。",
    "从以下公告段落抽取风险要素：{text}",
)
```
> 注意：实现走「JSON Schema 提示 + response_format=json_object + model_validate_json」，
> 因为 DeepSeek thinking 模式不支持 with_structured_output 的 tool_choice 路径。

## 防幻觉约定（赛题硬要求）
1. 证据必须**逐字来自原文**（公告/问询函原句），禁止 LLM 转述；
2. 抽取类 prompt 必须要求输出 `evidence` 字段并校验能在原文中找到；
3. 归因叙事生成后过 `validate_narrative`（backend/agents/attributor.py）校验证据白名单；
4. `evaluation_ground_truth` 仅用于评估，**不作预测特征**。

## 各环节 prompt 骨架
| 环节 | system | 关键要求 |
|---|---|---|
| 公告风险抽取 | 监管问询领域专家；按官方 taxonomy 分类 | 输出类别/严重度/证据原文；无证据返回空 |
| 归因叙事 | 风控分析师；只允许引用证据池 | 每个论断绑定 evidence_id；无证据不写 |
| 财务解读（可选） | 财务专家 | 结合行业特征解读异常，不重复罗列指标 |
| 代码解析（可选） | 不鼓励 | 项目已实现代码解析，勿用 LLM 替代确定性逻辑 |

## 参数建议
- 温度 0.1（低温度稳定输出）；max_tokens 2000 默认
- 需要推理时允许 thinking（chat 默认），结构化输出走 json_object（已兼容）
