# 技能 03 · 建模与评估

## 预测建模 Agent（backend/agents/predictor.py）
- **查表推理**（对齐比赛口径）：按 (company, as_of) 从建模数据集取 `report_period ≤ as_of` 的最新一行 → 按 manifest 特征清单截取 → 三模型集成
- **集成权重**：RF 0.30 + LightGBM 0.35 + XGBoost 0.35
- **SHAP**：LightGBM `pred_contrib`（TreeSHAP）作为集成贡献代理，Top-K 写入 `shap_features`
- **容错**：每个模型单独 try/except（单模型失败不打断窗口）；RF 强制 `n_jobs=1`（Windows 受限环境 WinError 5 规避）；公司不在数据集内 → 优雅降级"未预测"
- 公司代码需带后缀（如 000004.SZ）
