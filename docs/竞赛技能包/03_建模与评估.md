# 技能 03 · 建模与评估

## 预测建模 Agent（backend/agents/predictor.py）

- **实时推理（主路径）**：以公告研读 F1 标量 + 财务异常 F2-F6 实时值为数据源，按 `models_manifest.json` 每窗口特征清单组装向量（`backend/skills/feature_composer.py`）；
  - 缺失列（F1 语义 50 维、governance_year 等实时拿不到的）用训练集中位数兜底（`backend/data/modeling/fill_median_{30,60,90}d.csv`，离线数据只做兜底初始化）；
  - 审计字段：`data_source=realtime`、`coverage`（实时覆盖率，实测 000004.SZ 约 29%）；无实时财务数据时自动回落 `offline_lookup` 查表路径；
- **查表推理（兜底）**：`report_period ≤ as_of` 最新一行 → 三模型集成（与旧版一致）；
- **集成权重**：RF 0.30 + LightGBM 0.35 + XGBoost 0.35；**SHAP** = LightGBM `pred_contrib` 代理；
- **容错**：每模型单独 try/except；RF 强制 `n_jobs=1`；公司无数据 → "未预测"降级。

## 实时数据源分工（重要）

| 特征族 | 数据源 | 实时方式 |
|---|---|---|
| F1 语义 50 维 | 离线建模表（实时拿不到） | 中位数填充 |
| F2 财务 67 维 | 东财在线现算（f2_calc，列名已与训练表对齐） | 实时 |
| F3 市场 35 维 | 腾讯行情在线（market_fetch） | 实时 |
| F4 舆情 | 股吧在线爬取优先（30s 超时）→ 离线表兜底 | 实时/兜底 |
| F5 治理 | 股东结构在线爬取优先（30s 超时）→ 离线表兜底 | 实时/兜底 |
| F6 问询历史 | **公告研读 Agent**（巨潮公告列表 → inquiry_features.py） | 实时（窗口内无问询公告→全 0） |
