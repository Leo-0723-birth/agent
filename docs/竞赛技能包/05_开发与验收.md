# 技能 05 · 开发规范与验收清单

## 自测入口（改动后必跑）
| 命令 | 验证什么 |
|---|---|
| `python -m backend.agents.orchestrator` | 全流程 7 环节 done + 预测非空（000004.SZ） |
| `python -m backend.agents.graph` | LangGraph 直接跑图（trace 摘要） |
| `python -m backend.agents.predictor` | 预测 + SHAP |
| `python -m backend.llm` | LLM 通道状态（LangChain 可用性） |
| `pytest backend/tests -q` | 单元测试（AppTest 页面 + dashboard_utils 等） |

## 页面约定
- 单入口：`导航入口.py`（8501，st.navigation 聚合 7 页）——日常只用这个
- 独立审计页：公告研读 8502 / 财务异常 8503 / 预测建模 8504 / 案例匹配 8505 / 归因分析 8506 / 报告生成 8507
- 启动：双击 `启动导航入口.bat`（GBK+CRLF，勿改编码）或 PyCharm「导航入口 (streamlit)」
- `.streamlit/config.toml` 已关闭邮箱引导；**不要删**
- 页面文件**不要改名/加前缀**（曾因 `(1)~(7)` 前缀导致全部引用失效）

## LLM 约定
- 唯一入口 `backend/llm.py`：`chat` / `chat_json` / `chat_structured`（Pydantic）
- LangChain 通道异常自动回落 requests 直连，Agent 无需感知
- DeepSeek thinking 模式不支持 tool_choice → 结构化输出走 JSON Schema + json_object

## git 规范
- 提交信息用约定式（feat/fix/docs/refactor），正文列要点 + 验证结果
- **推送需用户确认**；改写提交说明用 `git commit --amend` + `git push --force-with-lease`
- 大权重不入库（.gitignore：backend/models/embedding/、backend/data/cache/）

## 答辩演示清单
1. 打开 http://localhost:8501（主控页默认）→ 输入 000004.SZ → 开始扫雷
2. 展示预测概率 + 风险等级 + SHAP 归因（预测建模页 8504 可单开）

4. 强调：7 Agent 全链路 trace、证据绑定原文防幻觉、LangGraph 图编排
