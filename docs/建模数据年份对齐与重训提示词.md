### 步骤 B｜在 `build_modeling_dataset.py` 注入年份过滤
在文件顶部导入后新增一个工具函数，并在**每一处原始数据 load 之后、下游使用之前**调用它：

```python
import pandas as pd
MIN_YEAR = 2021  # 剔除 2020，2021Q1 起

def keep_2021plus(df, period_col="report_period", year_col=None):
    """剔除 2020 及更早年份的记录；report_period 形如 %Y%m%d 或含 .0。"""
    if year_col is not None and year_col in df.columns:
        return df[df[year_col].astype(int) >= MIN_YEAR].copy()
    rp = pd.to_datetime(
        df[period_col].astype(str).str.replace(".0", "", regex=False),
        format="%Y%m%d", errors="coerce")
    return df[rp.dt.year >= MIN_YEAR].copy()
```

需要插入过滤的位置（对应脚本内原代码）：
1. F1 选取骨架用的 `_f2_sel`：`_f2_sel = keep_2021plus(_f2_sel)`（在 `astype(str)` 之后）。
2. F1 选取用的 `_events`：`_events = keep_2021plus(_events, year_col="year")`。
3. F1 主表 `f1`（在 `report_period` 已 `strftime("%Y%m%d")` 之后）：`f1 = keep_2021plus(f1)`。
4. F2–F6（在 `norm()` 之后）：`f2, f3, f4, f5, f6 = [keep_2021plus(d) for d in (f2, f3, f4, f5, f6)]`。
5. 标签构建用的 `events`（第 5 节）：`events = keep_2021plus(events, year_col="year")`。

> 要点：`build_modeling_dataset.py` 每次运行都会**在 Train 集上重新用 Spearman 选 F1 Top-50** 并重建 `processed_dataset.csv`，因此只需重跑该脚本即可应用新年份口径，无需手工改 `F1_top50_features.csv`。
