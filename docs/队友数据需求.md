## F1 表需求

- `F1_semantic_features.parquet`（或 CSV）：F1 公告语义特征，**50 维**（`regulatory_inquiry_semantic_*`），键 `company_code + report_period`；
- 用于重建训练集 `processed_dataset.csv`（当前 F1 部分用训练集中位数兜底）。

## 导入方式

队友提供文件后放入 `backend/data/modeling/raw/`，然后：
```bash
python -m backend.scripts.build_modeling_dataset   # 重建 processed_dataset
python -m backend.scripts.train_models             # 重训三模型 × 三窗口 + SHAP
# 重建预测兜底字典（fill/）：按 processed_dataset Train 中位数重算
```
