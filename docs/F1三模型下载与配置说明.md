# F1 实时同口径三模型：下载与配置说明

## 一句话结论

实时扫雷要输出「与训练完全同口径的 50 维 F1 语义特征」，**必须本地准备好下面三套模型**。
缺失时系统会**刻意安全回退**（报 `实时F1与训练特征口径不一致（缺少 50/50 个语义特征）`），
而不是悄悄用规则/LLM 标量冒充 50 维特征 —— 这是设计行为，不是 bug。

---

## 为什么需要这三套模型

训练期的 F1 语义特征走的是完整流水线，实时侧必须复刻同一口径：

```
BGE-large-zh-v1.5 (CLS 池化)
   → 公告内主题 Top-50 召回（阈值 0.42、最多 8 主题）
   → bge-reranker-v2-m3 精排（每主题 Top-20、每公告 Top-100）
   → finbert-tone-chinese 情绪 + 确定性语境门控
   → 公告×主题行 → 208 维聚合 → 冻结 PCA50
```

三套模型任一缺失，都无法产出 `announcement_semantic_000~049` 这 50 个特征，
PredictorAgent 的兼容性闸门（`realtime_f1_compatibility`）就会判定口径不一致并回退历史查表。

| 用途 | HuggingFace 仓库 | 锁定 revision | 体积（约） |
|---|---|---|---|

| 精排（rerank） | `BAAI/bge-reranker-v2-m3` | `953dc6f6f85a1b2dbfca4c34a2796e7dde08d41e` | 2.3 GB |

> revision 是**训练锁定**的，必须精确一致，否则实时特征与训练指标口径会漂移。

## 如何下载

项目内默认已把 HuggingFace 走国内镜像（`backend/skills/embedding.py`）：

```python
os.environ.setdefault("HF_ENDPOINT", "https://hf-mirror.com")
```

因此用 `huggingface-cli` 或 `from_pretrained` 直接下载即可（国内无需代理）：

```bash
# 方式一：命令行下载（会自动放到 ~/.cache/huggingface/hub）
pip install -U "huggingface_hub[cli]"
HF_ENDPOINT=https://hf-mirror.com huggingface-cli download \
    BAAI/bge-large-zh-v1.5 --revision 79e7739b6ab944e86d6171e44d24c997fc1e0116

HF_ENDPOINT=https://hf-mirror.com huggingface-cli download \
    BAAI/bge-reranker-v2-m3 --revision 953dc6f6f85a1b2dbfca4c34a2796e7dde08d41e

HF_ENDPOINT=https://hf-mirror.com huggingface-cli download \
    yiyanghkust/finbert-tone-chinese --revision e91b1a3af10e1e8c9c03429d3cd7d5e9a1c8000d
```

下载完成后，模型快照位于（Windows 默认缓存）：

```
~/.cache/huggingface/hub/models--BAAI--bge-large-zh-v1.5/snapshots/79e7739b.../
~/.cache/huggingface/hub/models--BAAI--bge-reranker-v2-m3/snapshots/953dc6f6.../
~/.cache/huggingface/hub/models--yiyanghkust--finbert-tone-chinese/snapshots/e91b1a3a.../
```

## 如何配置 `.env`

在项目根 `.env` 中打开实时同口径 F1 并指向三套模型路径：

```bash
# 打开实时同口径 F1（auto 只在三模型齐全时才启用；true 允许首次下载）
F1_ONLINE_SEMANTICS_ENABLED=true

# 三套模型锁定 revision 的本地快照目录（按你的实际路径修改）
F1_BGE_MODEL_PATH=C:/Users/<you>/.cache/huggingface/hub/models--BAAI--bge-large-zh-v1.5/snapshots/79e7739b6ab944e86d6171e44d24c997fc1e0116
F1_RERANK_MODEL_PATH=C:/Users/<you>/.cache/huggingface/hub/models--BAAI--bge-reranker-v2-m3/snapshots/953dc6f6f85a1b2dbfca4c34a2796e7dde08d41e
F1_FINBERT_MODEL_PATH=C:/Users/<you>/.cache/huggingface/hub/models--yiyanghkust--finbert-tone-chinese/snapshots/e91b1a3af10e1e8c9c03429d3cd7d5e9a1c8000d
```

> `F1_ONLINE_SEMANTICS_ENABLED` 取值：
> - `auto`（默认）：仅当上面三条路径都存在时才启用，避免普通查询意外下载数 GB 权重；
> - `true`：允许 HuggingFace 首次自动下载（无网时请用上面的 `huggingface-cli` 预下载）。

配置后重启服务即可。

## 故障对照表

| 现象 | 根因 | 解决 |
|---|---|---|
| `缺少 50/50 个语义特征` / `实时F1与训练特征口径不一致` | 三套模型未配置，实时 F1 未启动（安全回退） | 按上文下载 + 配置 `.env` |
| `预测数据源为 unavailable` | 实时特征未达发布条件，且公司不在建模数据集内 | 配置 F1 后重试；或换一个在数据集内的公司 |
| 下载卡住/超时 | 未走 `hf-mirror` 镜像 | 设置 `HF_ENDPOINT=https://hf-mirror.com` |
