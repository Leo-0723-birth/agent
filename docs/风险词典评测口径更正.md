# 风险词典评测口径更正

## 结论

现有 v2.1 覆盖报告使用的 1483 条案例全部来自 Test + Validation，没有 Train。29 条新增规则是在这批案例上调试和统计的，因此 E07 76.5%、E02 72.4% 及“平均命中率约 40%”只能视为开发集诊断结果，不能对外作为泛化性能。

这不是规则内容失效。关键词和正则是人工领域知识，待修正的是验证集使用方式：调参和报告统计不应使用 Test。

## 已完成改动

1. 两份覆盖报告已将“验证集”改为“Test + Validation 诊断集”。
2. 报告已明确标注过拟合风险，禁止把平均命中率和主题命中率作为对外泛化指标。
3. v2.1 规则文件保留，不回滚规则内容。

## 正式评测口径

使用 `_official_eval/dataset_split_labels.csv` 按公司 split 过滤公告标注数据：

- Train：用于规则调试和主要开发报告；
- Validation：用于冻结规则后的阈值和版本选择；
- Test：只在最终方案冻结后进行一次盲测，不参与规则修改。

Train 公告评测报告必须同时记录 split、公司数、文档数、主题正样本数、命中率和误报率。当前仓库统计为 Train 公司 1,369 家；原始问询源覆盖其中 1,092 家、3,300 份问询函。若没有对应的 Train 公告正文与官方主题标签，不得从 1483 条案例推算 Train 指标，应先补齐数据资产。
