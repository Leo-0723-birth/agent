## 当前结论（2026-08-29）

训练模型使用的是全量公告运行产物的 50 维 PCA 特征：
`announcement_semantic_000` 至 `announcement_semantic_049`。训练原料来自
`D:\BaiduNetdiskDownload\run_20260826_001320_full\company_quarter_pca50.parquet`，
该文件共 39,140 行、1,957 家公司，时间锚点最大为 **2025-04-30**。

本分支已同时接入全量 F1 和实时同口径链路。训练模型由全量 PCA50 重新训练；
在线链路由 `fullrun_online_semantics.py` 生成公告×主题行，再由
`fullrun_f1_transform.py` 使用仓库内冻结的 imputer、scaler 与 PCA 生成固定 50 维。
若三套上游模型未配置或任一步失败，`realtime_f1_compatibility()` 会正确降级至
历史查表，不会把规则标量或历史 PCA 值伪装为实时特征。

## 训练 PCA50 的真实上游

全量管线的 PCA 输入共 208 维：

1. 公告正文按 600 字符 / 100 重叠切块；
2. BGE-large-zh-v1.5（固定 revision）CLS 向量；
3. 45 个风险主题召回（阈值、Top-K 固定）；
4. BGE reranker 精排；
5. FinBERT 情绪、否定/模板/强信号联合打分；
6. 公告级风险主题特征，再按 30/60/90/180 天聚合；
7. 与预测锚点以前已披露的财务市场字段 PIT 对齐；
8. 使用训练期固定的 imputer、scaler 和 PCA 投影至 50 维。

第 1—7 步由在线语义流水线执行，第 8 步由冻结转换器执行。冻结 PCA 文件加载前
强制校验 SHA256；208 维聚合和 50 维投影均有自动测试。现有 `scalar_features`
仍只用于报告展示，不会进入 `announcement_semantic_000~049`。

## 正确接入条件

只有在线服务实际运行上述 1—8 步，并把 50 个命名特征写入
`ctx.semantic.f1_model_features` 后，兼容性闸门才可通过。每次输出必须同时记录：

- BGE、reranker、FinBERT 与风险词典 revision；
- 208 维上游字段覆盖率与缺失字段；
- PCA 模型哈希及训练锚点；
- 当前公告的来源、日期和 PDF/OCR 解析状态。

环境变量 `F1_ONLINE_SEMANTICS_ENABLED=auto` 时，只有配置了三套本地模型目录才
启动；设为 `true` 可允许 HuggingFace 首次下载固定 revision。未启用时接口会明确
给出 `not_generated`；成功时输出 50 维并记录 PCA 哈希、模型 revision、锚点日期
和输入行数。
