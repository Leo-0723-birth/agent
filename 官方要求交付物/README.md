# 官方要求交付物

本目录集中存放东吴证券“基于 Agentic AI 的上市公司监管问询概率预测与扫雷预警算法探索”除技术答辩 PPT 外的全部交付材料。答辩 PPT 请放入 `00_技术答辩PPT/`。

## 快速运行

```powershell
cd D:\competition_agent
.\.venv\Scripts\python.exe 官方要求交付物\api_service.py
# 浏览器或客户端访问 http://127.0.0.1:8787/health
```

接口详情见 `04_API与运行脚本/README.md`。输入单个公司或公司列表，服务会调用完整 7-Agent LangGraph 流水线，返回预测、归因、案例、报告和 trace。

批量预测：

```powershell
.\.venv\Scripts\python.exe 官方要求交付物\04_API与运行脚本\batch_predict.py --companies 000004.SZ 000063.SZ
```

输出写入 `03_测试集结果/`，审计日志写入 `02_Agent推理日志/`。

## 目录

| 目录 | 内容 |

| `00_技术答辩PPT` | PPT 预留目录，后续答辩文件放这里 |

| `04_API与运行脚本` | API 服务、批量脚本和启动说明 |
| `05_关键证据与典型案例` | 证据白名单、相似案例和典型案例分析 |
| `06_算法架构设计说明` | 技术架构、数据流、Agent 编排和追踪约定 |
| `07_模型评估报告` | 预测、语义抽取、案例检索和可解释性评估口径 |

| `09_交付验收清单` | 对照赛题技术指标和成果交付逐项验收 |

## 重要边界

- 预测输出是未来窗口内监管问询风险的方向性概率，不构成投资建议。
- 当前默认离线数据和模型资产优先；联网公告源、LLM 和 FinBERT 都是可选开关。
- `evaluation_ground_truth` 只用于评估/案例标签，不进入预测特征，避免标签泄漏。
- 真实部署前应使用正式封存测试集重新运行 `batch_predict.py`，并将结果归档到 `03_测试集结果/`。

## 当前可直接查验的成果

无需执行脚本即可查看：

1. `03_测试集结果/测试集结果数据表.md`：三窗口样本数、正负样本、混淆矩阵、模型指标和 60 天风险前十名。
2. `03_测试集结果/predictions_60d.csv`：7,499 条逐样本精确预测记录。
3. `06_算法架构设计说明/特征构建与选择说明.md`：F1 300 维筛至 50 维的规则和前 20 个重要特征。
4. `07_模型评估报告/模型评估报告.md`：当前模型摘要的三窗口指标和官方指标状态。

本交付包的核心展示对象是已生成的表格和报告；脚本只用于复现和更新，不是评委必须完成的前置步骤。
