# 部署说明

## Windows 本地演示

```powershell
cd D:\competition_agent
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run 导航入口.py --server.port 8501
```

浏览器访问 `http://127.0.0.1:8501`。需要 API 时运行 `官方要求交付物\run_api.bat`，默认端口 8787。

> **端口约定说明**（避免多入口冲突）：
> - 项目内**主 FastAPI 入口**为根目录 `start_api.bat`，默认端口 **8000**。双击后一个窗口运行 uvicorn，然后访问 `http://localhost:8000`。
> - 根目录 `start_api_verify.bat` 与主入口同端口（8000），会打开两个窗口：一个运行 uvicorn，另一个等待服务就绪后**自动打开默认浏览器**跳转到 `http://127.0.0.1:8000`。二者不可同时启动，否则会产生端口占用冲突。
> - `官方要求交付物\run_api.bat`（`api_service.py`）为**独立交付的纯标准库 HTTP 服务**，默认端口 **8787**，仅监听 `127.0.0.1`，与上述 FastAPI 服务互不关联，按需二选一启动。
> - Streamlit 主控 8501 为可视化导航入口，与 API 服务相互独立。

### 一键启动并自动打开浏览器

在资源管理器中直接双击：

```text
D:\competition_agent\start_api_verify.bat
```

执行流程：
1. 弹出「API Server」窗口启动 FastAPI 服务；
2. 主窗口自动检测 `/api/health`，服务就绪后调用默认浏览器打开 `http://127.0.0.1:8000`；
3. 关闭「API Server」窗口即可停止服务。

如果浏览器没有自动弹出，请检查系统默认浏览器是否已设置。

## 离线模式

设置 `ANNOUNCE_SOURCE=local`，并确保离线公告快照、模型、案例库和标签资产存在。LLM、FinBERT、联网公告源均可关闭；关闭语义向量时自动使用标签检索降级路径。

## 生产化建议

使用进程管理器托管 API，前置鉴权、限流和 HTTPS；将 `02_Agent推理日志` 与 `03_测试集结果` 挂载到独立持久卷；定期更新公告索引和模型版本，并保留 `as_of`、数据快照和 manifest 以支持审计回放。
