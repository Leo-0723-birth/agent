# 测试集预测结果

`batch_predict.py` 会生成：

- `prediction_results_YYYYMMDD_HHMMSS.csv`：公司、窗口概率、风险等级、置信度、数据源和追踪步数。
- `prediction_results_YYYYMMDD_HHMMSS.jsonl`：每家公司完整结构化结果，含报告、归因、案例和 trace。

正式评测请固定 `as_of`、数据源和模型版本，并把 AUC、Top 10% 覆盖率、F1 与语义/案例评测结果填入 `../07_模型评估报告/模型评估报告.md`。

## 已归档的精确结果

当前目录已包含三份逐样本 CSV：30 天 7,500 条、60 天 7,499 条、90 天 7,499 条。60 天表中正样本 449 条、负样本 7,050 条；完整汇总、混淆矩阵和前十风险样本见 `测试集结果数据表.md`。

当前主展示窗口为 60 天：集成 AUC 0.8312、Top 10% 覆盖率 0.4633。F1 为 0.3368，会原样披露，不以 AUC 或 Top 10% 指标替代 F1。
